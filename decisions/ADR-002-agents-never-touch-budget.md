# ADR-002 Agents never touch budget

**Status:** Adopted

## Context

An Ads agent can optimize all day long. But Google's own recommendations push constantly to spend more, and an agent that follows them would happily do it.

## Decision

Agents can change keywords, search terms, negatives and campaign overlap on their own. Budget changes, in any channel, always go through me. Budgets follow a ramp plan set by leadership.

## Consequences

- The agent works on quality of spend, not quantity
- Leadership can trust the account because spend never moves without a human
- Upsell recommendations get dismissed automatically instead of debated
